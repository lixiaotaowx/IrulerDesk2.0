# 按钮信号链路文档

本文档记录了系统中主要按钮的功能名称、变量名及其信号指向的函数。

## NewUiWindow (主界面)

| 按钮功能 | 变量名 | 信号指向函数/逻辑 |
| :--- | :--- | :--- |
| 标签页切换 | tabBtn | Lambda (切换当前显示的页面索引) |
| 麦克风开关 | micBtn | Lambda (切换麦克风静音状态) |
| 系统设置 | settingBtn | NewUiWindow::systemSettingsRequested |
| 动态岛开关 | toolBtn1 | NewUiWindow::toggleStreamingIslandRequested |
| 发布公告/任务 | toolBtn2 | NewUiWindow::onBroadcastBtnClicked |
| 清除屏幕标记 | toolBtn3 | NewUiWindow::clearMarksRequested |
| 会议模式 | meetingBtn | NewUiWindow::onMeetingBtnClicked |
| 恢复语音通话 | callRestoreBtn | Lambda (恢复语音通话窗口) |
| 最小化 | minBtn | QWidget::showMinimized |
| 最大化/还原 | maxBtn | NewUiWindow::toggleFunction1Maximize |
| 关闭程序 | closeBtn | QWidget::close |
| 退出嵌入式观看 | backBtn | Lambda (stopEmbeddedWatching - 停止观看) |
| 拒绝邀请 | rejectBtn | Lambda (发送 invite_response reject 信号) |
| 接受邀请 | acceptBtn | Lambda (发送 invite_response accept 信号) |
| 关闭弹窗 | closeBtn (in popups) | Lambda (关闭提示窗口) |

## MainWindow (部分逻辑/弹窗)

| 按钮功能 | 变量名 | 信号指向函数/逻辑 |
| :--- | :--- | :--- |
| 挂断通话 | hangupBtn | Lambda (hangupCall - 挂断当前通话) |
| 发起观看 | m_watchButton | MainWindow::onWatchButtonClicked |
| 拒绝邀请(Toast) | rejectBtn | Lambda (发送拒绝信号并关闭Toast) |
| 接受邀请(Toast) | acceptBtn | Lambda (发送接受信号并关闭Toast) |
| 关闭Toast | closeBtn | Toast::deleteLater / Toast::close |
| 加入到任务(Toast) | addTaskBtn | Lambda (将通知内容添加到任务列表) |

## BroadcastNoticeDialog (公告/任务对话框)

| 按钮功能 | 变量名 | 信号指向函数/逻辑 |
| :--- | :--- | :--- |
| 关闭对话框 | closeBtn | QDialog::reject |
| 选择接收人 | m_selectUsersBtn | Lambda (打开 InviteUsersDialog 选择用户) |
| 发布公告 | m_publishBtn | Lambda (发送公告信息给选定用户) |
| 添加任务 | m_addTaskBtn | Lambda (打开 DateTimePickerDialog 添加新任务) |
| 任务完成状态 | cb (QCheckBox) | Lambda (更新任务完成状态并刷新列表) |
| 删除任务 | del (QPushButton) | Lambda (从 TaskManager 删除任务并刷新列表) |

## InviteUsersDialog (用户选择)

| 按钮功能 | 变量名 | 信号指向函数/逻辑 |
| :--- | :--- | :--- |
| 关闭/取消 | m_closeBtn | QDialog::reject |
| 邀请/确认 | m_inviteBtn | InviteUsersDialog::onInviteClicked |
